## CRITICAL — DO NOT REDESIGN THE EXISTING WEBSITE

This task is NOT a visual redesign.

The owner has spent significant time building and refining the existing UI and wants the core design preserved.

You must preserve the existing visual structure and component design wherever possible, especially:

- Navbar design
- Hero section visual design and layout
- Existing animation concepts
- Existing responsive layouts
- Product card design
- Existing interactive components
- Scroll effects and transitions
- Existing design language, spacing rhythm, and overall visual identity

Do NOT replace existing components simply because you personally prefer another design.

Do NOT rebuild the homepage from scratch.

Do NOT introduce a completely new design system.

Do NOT make broad visual changes unless they are necessary to fix a specific usability, accessibility, responsiveness, performance, or credibility problem.

### What you ARE allowed to change freely

You may substantially improve:

- Copy and messaging
- Headings and labels
- CTAs
- Incorrect statistics
- Placeholder content
- Testimonials
- Certification wording
- SEO metadata
- Product information architecture
- Trust/credibility content
- Forms
- Technical documentation presentation
- Content hierarchy inside existing components

You may also:

- Create new pages
- Create new sections
- Create new components
- Add missing B2B features
- Improve admin functionality
- Add datasheet/document functionality
- Add RFQ functionality
- Add buyer-specific content

New components and sections should visually fit the existing Noor Solar design system rather than introducing an unrelated visual style.

### Existing component rule

Before replacing or significantly restructuring an existing component:

1. Inspect its current implementation.
2. Determine whether the problem is actually design-related or only content/data-related.
3. Prefer modifying its content/data/behavior.
4. Preserve the visual implementation when it is already working well.

For example:

If the hero contains incorrect AC/HVAC content, replace the content and inappropriate imagery while preserving the existing hero layout, interactions, animation concept, and styling.

If the navbar works correctly, leave its design alone.

If a section only contains incorrect data, fix the data rather than redesigning the section.

### Refactoring rule

Technical refactoring is allowed when necessary, but the public-facing appearance should remain substantially the same unless a requested improvement specifically requires a visual change.

When uncertain, preserve the existing design.
