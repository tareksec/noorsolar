## Preloader
- `logo-icon.svg` uses separate rounded-cap bar, curve, and ray paths so GSAP can draw the mark without auto-trace noise.
- `logo-wordmark-white.webp` is cropped from the official white PNG and kept as a small raster fallback because the source lettering is not safely reproducible with a substitute font.
- The home preloader is implemented in `src/components/ui/site-preloader.tsx` and uses the official cropped wordmark WebP plus `public/logo/icon.png` for pixel-faithful icon rendering.
